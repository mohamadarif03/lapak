# Design System LAPAK (Light Theme)

## Warna Utama
- **Background Utama**: `#FFFFFF` (Clean White - bersih, nyaman di mata, kontras tinggi)
- **Kartu & Surface**: `#FFFFFF` (Surface White) dengan border halus `#E2E8F0`
- **Sidebar**: `#FAFCFA` (Subtle Crisp Light Green-White) dengan border `#E8EFE8`
- **Warna Teks Utama**: `#183C30` (Forest Ink - terbaca jelas dan tajam)
- **Warna Teks Sekunder**: `#657267` (Muted Olive)

## Brand Accent
- **Primary / Action**: `#174D3A` (Deep Forest Green)
- **Primary Soft / Secondary**: `#E8F0E6` (Sage Mist)
- **Muted Background Tint**: `#F4F6F4` (Light Sage Tint)
- **Gold Accent**: `#D8A75B` (Muted Gold) / `#F6EBD5` (Pale Gold Soft)

## Status
- **Sukses**: `#216E45` (Background: `#E4F3E8`)
- **Warning**: `#8A5700` (Background: `#FFF1CF`)
- **Error**: `#B3261E` (Background: `#FBE3E1`)
- **Info**: `#285A91` (Background: `#E3ECF9`)

## Aturan Tampilan
1. **Zero Emoji**: Tidak boleh ada emoji di web ini. Semua simbol menggunakan Lucide React icons.
2. **Light Mode Only**: Tampilan web selalu light mode dengan background putih bersih (`#FFFFFF`).
